## 三、已知问题（不阻塞日常使用）

| # | 问题 | 影响 | 备注 |
|---|---|---|---|
| P1 | 机型标识为供体值 `KB2000`/`OnePlus8T`/`brand=OnePlus` | 部分 OPPO/OnePlus 服务与三方 App 会误判机型 | `ro.product.model`、`ro.product.device`、`ro.product.name`、`ro.product.odm.model`、`ro.build.fingerprint` |
| P2 | `/odm/bin/hw/subsys_daemon` 崩溃：`libradioapis.so::QmiVsClient::getNecData` `__memcpy_chk_fail` | 部分射频诊断特性 | ODM 与 A16 radio APIs 不匹配 |
| P3 | `init second_stage` fork 在 `Service::RunService` abort ×2 | 某 service exec 失败（非致命） | 主 init 存活，不影响启动 |
| P4 | SELinux 仍 `permissive` | 安全性 | `androidboot.selinux=permissive`，需给 apexd 域补策略才能回 enforcing |
| P5 | 指纹 `gaia ... init_fault = 18` | 指纹可能不可用 | 需实测录入 |
| P6 | `su` 不在 adb shell PATH | 无法从 adb 直接提权 | 待确认 Magisk 环境完整性 |
